First-time setup

On air in four steps.

The Windows installer includes the application and its audio and GUI runtime libraries. Your radio hardware driver must be installed separately.

Prepare your receiver

For SDRplay hardware, install the latest Windows driver and API from the official SDRplay downloads page, then connect the device. For RTL-SDR, make sure a compatible Windows driver is installed.

Install DAB SDR GUI

Download the latest setup file from SourceForge, run it, and follow the installer. Windows may ask you to confirm that you want to run a newly downloaded application.

Select and scan

Open Settings > SDR Settings..., select your hardware backend, and press OK. Press Scan and wait while the available DAB channels are checked.

Start listening

Choose a station from the Station list and press Start. Use Stop before disconnecting the receiver or changing devices.

Receiver settings

Choose the hardware you have.

The selected backend, automatic gain control, and manual gain are saved for the next time you launch the app.

Default backend

SDRplay

Select SDRplay for supported RSP receivers. Install the vendor software first from sdrplay.com.

Alternative backend

RTL-SDR

Select RTL-SDR for compatible USB dongles. Confirm that Windows sees the receiver through the correct driver before scanning.

Settings/SDR Settings.../HAL backend/OK

Leave Automatic gain control enabled for a simple first setup. If you disable it, set the manual gain in dB. Stop and restart playback after changing SDR settings, and scan again when switching hardware.

OpenGL display

See the signal your way.

Open Settings > Spectrum Settings..., choose a display mode, and press OK. The change appears immediately and is remembered.

RTA bars

The default real-time analyzer view, ideal for reading the overall balance of the audio spectrum.

FFT curve

A continuous frequency curve for a more detailed view of peaks and valleys in the program audio.

LED bars

A segmented meter display inspired by classic hardware analyzers and studio equipment.

Tip: The spectrum shows decoded audio, so it becomes active after a station starts playing. Display mode does not affect reception or sound quality.
